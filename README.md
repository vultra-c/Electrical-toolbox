# 电学工具箱 · ElectroBox

面向 **小米手环 9 Pro（336 × 480）** 的 **Xiaomi Vela JS 轻应用**。
九年级电学的线路图求解 + 万能计算 + 公式速查，全部计算在手表本地完成，不联网。

> 出版包：`dist/com.physics.electrobox.release.1.0.0.rpk`（自签名，RSA-2048，10 年有效期）

---

## 一、它解决什么问题

| 痛点 | 本应用的做法 |
| --- | --- |
| 看不懂线路图、不会判断串并联 | **线路图实验室**：在表盘网格上点格放元件，自动用改进节点法（MNA）解出每个元件的 U / I / P，并判定通路 / 短路 / 断路 |
| 计算慢、公式记不牢 | **万能计算**：6 大题型，键盘输入，自动带单位换算与解题步骤 |
| 动态电路看不出示数怎么变 | **动态电路**：滑动变阻器限流 / 分压两种接法，直接给出电流表、电压表示数范围与变化趋势 |
| 伏安法接法选不对 | **伏安法**：内接 / 外接误差百分比、临界电阻、电表量程建议 |
| 考前临时抱佛脚 | **公式速查**（43 条 / 7 大类）+ **易错点**（8 个高频陷阱） |

## 二、功能清单

### 1. 线路图实验室（核心）

* 4 × 4 节点网格，24 条可放置元件的「格边」
* 10 种元件：导线 / 定值电阻 / 小灯泡 / 电源 / 开关 / 电流表 / 电压表 / 滑动变阻器 / 电动机 / 电热器
* 操作：**点空格 → 选元件 → 键盘填数值**；再点一次可改数值、切开关、替换、删除
* 底部实时显示 `I / R / U / P总`，改一个值立刻重算
* 6 个教科书预设电路：串联 / 并联 / 伏安法 / 滑变限流 / 滑变分压 / 串并联混合
* 点「求解」进入结果页：总览 + 每个元件的电压电流功率 + 电流表电压表读数 + 验算提示
* 电路草稿自动存本地，下次打开继续画

**求解算法**：`src/common/circuitEngine.js`

* 改进节点法（MNA）：未知量为各节点电压 + 所有电压源支路电流
* 导线 / 闭合开关 / 电流表 → 0 V 电压源；电压表 / 断开开关 → 断路
* 电源可设内阻（理想电源被短路时报「无解」并提示加内阻）
* 高斯消元 + 部分主元；节点对地加 1e-9 S 漏电导，保证浮空子网可解
* 自动判定：通路 / 短路（等效电阻 < 0.05 Ω）/ 断路（电流 ≈ 0）

**正确性验证**：6 个预设电路的电流、电阻、功率、分压分流均与手算结果逐项一致
（例如：串联 3 V + 10/10/20 Ω → I = 75 mA、R = 40 Ω、P = 225 mW，分压 0.75/0.75/1.5 V；
并联 6 V + 10 Ω‖20 Ω → I = 0.9 A、R = 6.667 Ω，支路 0.6 A / 0.3 A）。

### 2. 万能计算

| 题型 | 覆盖内容 |
| --- | --- |
| 欧姆 | I = U/R、U = IR、R = U/I 三量互求 |
| 串并 | 串联 / 并联 2~4 个电阻，等效电阻、总电流、总功率、每个电阻的分压分流 |
| 功率 | P = UI、P = I²R、P = U²/R，同时给出消耗电能 W = Pt |
| 额定 | 额定 vs 实际：R = U额²/P额、实际功率、亮度判断 |
| 电能 | W = Pt、t = W/P、P = W/t、Q = I²Rt、Q = UIt，1 度 = 3.6×10⁶ J |
| 换算 | 电流 / 电压 / 电阻 / 功率 / 电能 / 时间 六类单位互转 |

### 3. 动态电路

* 限流接法：I ∈ [U/(R0+Rmax), U/R0]，U定 ∈ [U·R0/(R0+Rmax), U]
* 分压接法：U ∈ [0, U·RL/(RL+Rmax)]，可从 0 连续调到接近电源电压
* 滑片移动的增减趋势、开关闭合前后干路电流对比

### 4. 伏安法测电阻

* 内接法 R测 = Rx·Rv/(Rx+Rv)（偏小，适合大电阻）
* 外接法 R测 = Rx + Ra·Rx/(Rx+Rv)（偏大，适合小电阻）
* 相对误差百分比、临界电阻 R临 = √(Ra·Rv)、电表量程建议

### 5. 公式速查 / 易错点 / 使用说明

* 43 条公式，7 大分类，分类筛选
* 8 个中考高频易错点
* 玩法说明 + 10 种元件符号对照

## 四、构建方法

```bash
# 1. 安装依赖（AIoT-toolkit 2.0.5）
npm install

# 2. 生成发布签名（仅首次；私钥已 gitignore，不会进仓库）
sh tools/make_sign.sh

# 3. 调试包
npm run build       # -> dist/com.physics.electrobox.debug.1.0.0.rpk

# 4. 发布包（带签名，代码压缩）
npm run release     # -> dist/com.physics.electrobox.release.1.0.0.rpk

# 或者一步构建两个包（自动归档到 release/）
npm run build:all

# 重新生成图片资源（改了 tools/gen_icons.py 后）
npm run icons
```

### 签名说明

* `sign/certificate.pem` —— **已提交到仓库**，任何人可用它校验 rpk 的签名是否有效
* `sign/private.pem` —— **不提交**（已写入 `.gitignore`），必须自行生成
* 换机器或克隆仓库后，先跑 `sh tools/make_sign.sh` 生成自己的密钥再构建
* 私钥丢失不影响已发布的 rpk（签名已封装在包内），但会生成与仓库里证书不匹配的新签名
* 本项目用自签名证书，可直接装机调试；上架小米 vela 正式商店需换成开发者证书重新签名

### 安装到设备

```bash
# 连上手表后
adb install -r dist/com.physics.electrobox.release.1.0.0.rpk
```

或用 `AIoT-IDE` 打开项目后点「发布 / 调试」推送到模拟器或真机。

> 本项目使用自签名证书（`sign/certificate.pem`），可直接装机调试；
> 私钥 `sign/private.pem` 不在仓库里，需自行运行 `sh tools/make_sign.sh` 生成；
> 若要上架小米 vela 正式商店，需要换成你自己的开发者证书重新签名。

## 五、历史代码

每次改动后执行：

```bash
sh tools/snapshot.sh v1.0.0        # 存到 history/v1.0.0/
sh tools/snapshot.sh                # 不带参数则用时间戳
```

快照里的 `.ux` 文件会被重命名为 `.ux.bak`，避免被 aiot-toolkit 当成源码一起编译。

## 六、适配说明

* 设计宽度 `336`，页面固定 `336 × 480`，对应手环 9 Pro
* `minPlatformVersion: 1100`，`deviceTypeList: ["watch"]`
* 主题为深色 OLED：底色 `#05070C`，主色 `#1B4FD8`，数据高亮 `#5FE3FF`
* 按下反馈用 `touchstart` / `touchend` 切 class 实现（Vela 不支持 `:active` 伪类）
* 列表、卡片、键盘等公共样式集中在 `src/common/style.css`，各页面用 `@import` 引入
* 页面跳转传参用 `router.push({ uri, params })` + 目标页 `protected` 声明
